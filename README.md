# Unnamed VPN — Telegram Bot (aiogram 3 + 3x-ui + Crypto Pay)

Бот **только** управляет пользователями/оплатой/подписками. Сам VPN-сервер
(Xray/3x-ui) и white-list разрешённых доменов/IP настраиваются отдельно,
на стороне панели 3x-ui — бот лишь дёргает её API.

## Возможности

- Регистрация пользователя при `/start`
- Карточка профиля (баланс, ссылка-подписка, срок действия) + меню в стиле
  «Подключить устройство / Продлить подписку / Баланс / Устройства /
  Поделиться подпиской / О сервисе»
- Баланс пользователя: пополнение через LAVA (пресеты суммы + произвольная
  сумма) и оплата подписки прямо с баланса, без похода к провайдеру
- Выбор тарифа и оплата в USDT (или другом активе) через Crypto Pay API (@CryptoBot),
  либо в рублях картой/СБП через LAVA (lava.ru)
- После оплаты — автоматическое создание/продление клиента в 3x-ui и выдача ссылки-подписки
- Промокоды 4 типов: бонусные дни, начисление на баланс, скидка % (в т.ч. 100% =
  бесплатно) на будущую покупку, партнёрский код (пробные дни + скидка % разом).
  Скидка учитывает лимит активаций, срок действия, один код — один раз на пользователя
- Ежедневная фоновая проверка: отключение доступа по истечении срока + напоминания за 3 дня
- `/stats` для админов (кол-во активных/истёкших подписок)

## Установка

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (через запятую, если несколько)
- `XUI_BASE_URL/USERNAME/PASSWORD` — доступ к панели 3x-ui
- `XUI_INBOUND_ID` — id инбаунда, в котором бот создаёт клиентов
- `XUI_SUB_BASE_URL` — базовый URL сервиса подписок 3x-ui
- `CRYPTO_PAY_TOKEN` — токен из @CryptoBot → Crypto Pay → Create App
- `LAVA_API_TOKEN` — токен из lava.ru/dashboard/settings/api (для приёма
  платежей от клиентов нужен статус самозанятого/ИП/юрлица и модерация
  проекта в личном кабинете LAVA)
- `VPN_NAME` — название сервиса, подставляется в тексты бота (по умолчанию "Unnamed VPN")

Запуск:

```bash
python main.py
```

## Что нужно донастроить под себя

1. **Список разрешённых доменов**: в панели 3x-ui (Xray Configs → Routing) настройте
   routing rules так, чтобы разрешён был трафик только на нужные домены/IP —
   это делается один раз на уровне сервера, бот в этот процесс не вмешивается.
2. **`services/threexui_api.py` → `create_client`**: поля клиента заданы примером
   под протокол VLESS. Если ваш инбаунд использует VMess/Trojan/Shadowsocks —
   поправьте набор полей под соответствующий протокол.
3. **Сервис подписок 3x-ui**: включите его в Panel → Settings → Subscription
   Settings и укажите итоговый базовый URL в `XUI_SUB_BASE_URL`.
4. **Тарифы**: список в `config.py` → `PLANS` (название, дни, цена в USDT и в RUB —
   рублёвые цены сейчас проставлены примерно, поправьте под свой курс/маржу).
   Пресеты пополнения баланса — там же, `TOPUP_PRESETS_RUB`.
5. **Баланс/устройства**: устройства безлимитны по количеству (лимит на клиента
   в 3x-ui не выставляется — `limitIp: 0`). Пополнение баланса сейчас идёт только
   через LAVA (в рублях); если нужен топ-ап через CryptoBot — сообщайте, добавлю.
6. **Проверка оплаты** сейчас идёт по кнопке «Я оплатил» (polling у CryptoBot/LAVA).
   Для мгновенного зачисления можно дополнительно поднять вебхуки —
   сообщайте, если нужно, добавлю обработчик на aiohttp/FastAPI.
7. **Промокоды** создаются/управляются админ-командами в Telegram (см. ниже),
   отдельной админ-панели нет.
8. **LAVA (`services/lava_api.py`)**: реализация основана на официальной
   open-source библиотеке LAVA (эндпоинты `api.lava.ru/invoice/create`,
   `/invoice/info`), т.к. сама dev.lava.ru рендерится через JS и не была
   доступна для автопроверки на момент написания. Перед боевым запуском
   сверьте формат ответа с актуальной документацией в личном кабинете —
   он мог измениться.

## Админ-команды (Telegram)

- `/stats` — количество активных/истёкших подписок
- `/promo_create КОД ТИП ЗНАЧЕНИЕ [max=N] [expires=YYYY-MM-DD] [uses=N] [valid_days=N] [discount=N]`
  — создать промокод. Типы:
  - `days` — бонусные дни подписки сразу: `/promo_create WELCOME7 days 7 max=100`
  - `balance` — начисление на баланс сразу (₽): `/promo_create SALE300 balance 300 max=50 expires=2026-12-31`
  - `discount` — скидка % на будущую покупку (100 = бесплатно). `uses` — сколько раз
    можно применить скидку (по умолчанию 1, `uses=0` = без лимита до истечения срока),
    `valid_days` — сколько дней скидка действует после активации (по умолчанию бессрочно):
    - `/promo_create FREEMONTH discount 100 uses=1 valid_days=3 max=50` — 100% на первую покупку в течение 3 дней
    - `/promo_create SPRING15 discount 15 uses=0 valid_days=30 max=500` — 15% на все покупки 30 дней
  - `partner` — партнёрский код: пробные дни (ЗНАЧЕНИЕ) + скидка % (`discount=N`, обязателен) разом:
    - `/promo_create PARTNER15 partner 3 discount=15 uses=0 valid_days=365 max=1000` —
      3 дня триала сразу + 15% скидка на покупки в течение года
- `/promo_list` — список всех промокодов со статусом и статистикой использования
- `/promo_disable КОД` — отключить промокод

## Структура проекта

```
main.py                  — точка входа, регистрация роутеров, планировщика и WebApp API
config.py                — конфиг из .env + тарифные планы
database/
  models.py              — User, Subscription, Invoice, PromoCode, PromoRedemption (SQLAlchemy)
  db.py                  — async-хелперы для работы с БД (SQLite)
handlers/
  user.py                — /start, меню, покупка, баланс, промокоды, проверка оплаты
  admin.py                — /stats, /promo_create, /promo_list, /promo_disable
services/
  threexui_api.py          — клиент API панели 3x-ui
  cryptobot_api.py         — клиент Crypto Pay API (@CryptoBot)
  lava_api.py              — клиент LAVA Wallet API
  expiry_checker.py        — фоновая проверка истекающих подписок
keyboards/keyboards.py    — инлайн-клавиатуры
webapp/
  api.py                  — REST API (aiohttp) для мини-приложения — тот же личный кабинет,
                             что и меню бота, но в виде Telegram Mini App
  auth.py                  — проверка подписи Telegram WebApp initData
webapp-frontend/          — статический фронтенд мини-приложения (HTML/JS, без сборки),
                             деплоится отдельно на Vercel/Netlify
```

## Мини-приложение (Telegram Mini App / WebApp)

Личный кабинет как полноценное веб-приложение внутри Telegram: баланс, подписка,
покупка/продление тарифов, промокоды, устройства — то же самое, что в меню бота,
но в виде интерфейса.

- **Backend** (`webapp/api.py`) стартует вместе с ботом (тот же `main.py`), слушает
  `API_HOST:API_PORT` (по умолчанию `0.0.0.0:8080`). Наружу нужно пробросить через
  reverse-proxy (nginx/caddy) с HTTPS на отдельном домене — без HTTPS Telegram WebApp
  не сможет к нему обратиться.
- **Frontend** (`webapp-frontend/`) — статический сайт, деплоится отдельно
  на Vercel/Netlify. Инструкция — в `webapp-frontend/README.md`.
- Авторизация — через `initData`, который Telegram сам подписывает на клиенте;
  backend проверяет подпись на каждый запрос (см. `webapp/auth.py`), отдельных
  логинов/паролей не требуется.

Настройка в `.env`: `WEBAPP_URL`, `WEBAPP_SHORT_NAME`, `API_HOST`, `API_PORT`,
`API_CORS_ORIGIN` (см. `.env.example`). Если `WEBAPP_URL` не задан — кнопка
мини-приложения просто не появится, бот продолжает работать как обычно через меню.

**Прямая ссылка на приложение для промокодов.** Кнопка «🎁 Активировать» у
промокодов открывает мини-приложение напрямую (минуя чат с ботом), если задан
`WEBAPP_SHORT_NAME`. Чтобы получить short name:

1. Откройте `@BotFather` → `/mybots` → выберите бота → `Bot Settings` →
   `Mini Apps` (или `Configure Mini App` в новых версиях) → создайте приложение,
   указав тот же URL, что и в `WEBAPP_URL`, и задайте короткое имя, например `app`.
2. Впишите это имя в `.env` как `WEBAPP_SHORT_NAME=app`.
3. Перезапустите бота.

Без этой настройки кнопка «Активировать» по-прежнему работает — просто
открывает чат с ботом и активирует промокод там (старое поведение).
